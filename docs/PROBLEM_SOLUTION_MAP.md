# Streako Elite: problem-to-solution map

## Product direction

Build an original interactive life planner informed by the information architecture and interaction patterns visible in public productivity planner listings: compact progress dashboards, weekly/day columns, monthly overview, recurring activities, habit checkmarks, and visual summaries. This is not a pixel-for-pixel copy of proprietary spreadsheet designs or artwork.

## Problems and product responses

| User problem | Product response | How to verify |
| --- | --- | --- |
| Tasks, habits, health, and life admin are scattered across different systems | One planner draws from the same task and habit records as Today, Habits, and Insights | Complete an item in Planner and verify Today / habit matrix reflect it |
| Users lose track of dates and deadlines | Selectable week and month calendars with previous/next navigation and a Today control | Navigate to another week and month, select a date, and inspect that day's agenda |
| A flat checklist does not reveal when work should happen | Group tasks by time of day or life category; show planned time and estimated duration | Switch Group by Time / Category and confirm ordering/group labels |
| Large projects are hard to start | Capture a clear activity, estimated minutes, priority, and a focusable next action | Create a task and use the Focus view to work on it |
| Repeated chores require repeated planning | Recurrence options: daily, weekdays, weekends, weekly, monthly | Create a recurring task and confirm it appears on eligible dates |
| Completing today's repeat could incorrectly mark future repetitions done | Repeating tasks keep a separate completion record for every date | Complete a recurring task today, navigate to tomorrow, and confirm tomorrow remains unchecked |
| Habit consistency is hard to see | Daily progress bar, weekly tick grid, and monthly activity markers | Toggle a habit on a past eligible date and confirm all views use that log |
| People can feel punished for missing one day | Flexible scheduling and non-punitive progress, without a forced perfect-streak requirement | The UI reports progress neutrally and permits editing past dates |
| Too many choices create cognitive load | Default weekly view, clear date-level agenda, and filter/group controls | A new user can reach a selected day's checklist in one click |

## Research and practice references

- CHADD, “Time Management and ADHD: Day Planners”: planners may help organize schedules and responsibilities; it highlights time-management, organization, and working-memory challenges. https://chadd.org/for-adults/time-management-planner/
- Harkin et al. (2016), “Does monitoring goal progress promote goal attainment? A meta-analysis of the experimental evidence,” *Psychological Bulletin* 142(2), 198–229. It analyzed 138 studies (N=19,951) and found that progress-monitoring interventions improved goal attainment on average. https://doi.org/10.1037/bul0000025
- Gollwitzer & Sheeran (2006), “Implementation Intentions and Goal Achievement: A Meta-analysis of Effects and Processes.” Reviews if–then plans specifying when, where, and how to act. https://doi.org/10.1016/S0065-2601(06)38002-1
- Stanford Behavior Design Lab, Fogg Behavior Model: behavior design considers motivation, ability, and prompts. https://behaviordesign.stanford.edu/resources/fogg-behavior-model

These sources inform product hypotheses; they do not establish that Streako Elite itself has been clinically tested or proven to improve outcomes.

## Current implementation boundaries

- Tasks and habits use local browser storage. They are not synchronized across devices or accounts.
- Recurrence is generated by the planner at display time; it does not create external calendar events or send notifications.
- There is no backend, multi-user sharing, Google Calendar integration, or server reminder service in this iteration.
- Accessibility, recurring-date edge cases, and data persistence deserve additional automated tests before a wider release.
